QUICK START - 3 MINUTES

1. Setup:
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

2. DB:
rm db.sqlite3
python manage.py makemigrations manual_assistant
python manage.py migrate

python manage.py shell
